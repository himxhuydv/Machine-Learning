# Imbalanced Data 
In one feature when one sample frequency is higher then the other sample which resultant into the data imbalanced.
For ex:
Fraud detection
1000 data 
960=fraud(majority)
40=no fraud(minority) 
this will resultant into the data imbalanced(majority dominate minority).
**Imbalanced datasets appear in:**
Fraud detection
Medical diagnosis
Spam Detection
in these mdoel we get the imbalanced data.
because most of the cases in this can be positive will be dominate or negative will be dominate.
**Consequences**
**Bias**:model will predict wrong output because the model is gettng input is imbalanced data.which literally predict wrong output.
**Higher accuracy but Poor Performance**:Model may have higher accuracy due to traning on the imbalanced data but perform very poor into real world data.
**Missed Insight**:Model can some time cannot learn the important thing because of the minority is not important.
