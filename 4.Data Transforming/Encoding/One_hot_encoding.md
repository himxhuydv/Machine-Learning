# One hot encoding 
Baically we make the binary coloumn and distinct the feature with 0 and 1.we use this where we don't want to show any kind of relation,rank,order.
best for the nominal data.
for ex:
         red     blue     green 
red       1        0        0
blue      0        1        0
green     0        0        1


**Drawback**
1.Dimensionality increase as the feature increase.
2.Increase the data size and increase the work of computation
